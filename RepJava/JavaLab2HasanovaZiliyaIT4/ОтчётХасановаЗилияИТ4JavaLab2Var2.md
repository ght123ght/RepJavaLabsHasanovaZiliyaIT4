## Задача 2
### Текст задачи
Человек.		 Создайте	сущность	Человек,	которая	описывается:	 
    • Имя:	строка	 
    • Рост:	целое	число	 
Может	 возвращать	 текстовое	 представление	 вида	 “Name,	 рост:	 height”,	 где	 Name	 и	 height	 это	 переменная	с	именем	и	ростом.	 
Необходимо	создать	и	вывести	на	экран	следующих	людей:	 
    • Человек	с	именем	“Клеопатра”	и	ростом	152	 
    • Человек	с	именем	“Пушкин	”	и	ростом	167	 
    • Человек	с	именем	“Владимир	”	и	ростом	189
### Алгоритм решения
1. Определить сущность Человек, которая должна содержать два поля:  
    - имя (тип String);  
    - рост (тип int).
2. Реализовать конструктор класса Person, который принимает имя и рост и сохраняет их во внутренние поля объекта.
3. Реализовать метод toString(), который возвращает строку вида: "Name, рост: height", где Name - значение поля имени, а height - значение поля роста.
4. Создать три объекта класса Person с указанными параметрами:  
    - имя Клеопатра, рост 152;  
    - имя Пушкин, рост 167;  
    - имя Владимир, рост 189.
5. Вывести созданные объекты на экран. При выводе автоматически вызывается метод toString(), который формирует корректное текстовое представление человека.

Необходимо	создать	следующие	имена:	 
    • Клеопатра	 
    • Пушкин	Александр	Сергеевич	
    • Маяковский	Владимир	 
Обратите	 внимание,	 что	 при	 выводе	 на	 экран,	 не	 заданные	 параметры	 никак	 не	 участвуют	 в	 образовании	строки.	
### Алгоритм решения
1. Определить структуру имени. Имя состоит из трёх возможных частей: фамилия, личное имя, отчество. Любая часть может отсутствовать.
2. Создать класс Name с тремя приватными полями: surname, personalName, patronymic.
3. Реализовать три конструктора.
    - Фамилия + имя + отчество  
    - Фамилия + имя  
    - Только имя  
Чтобы создавать все нужные варианты.
4. Реализовать метод toString().  
    - начать с пустой строки  
    - если фамилия задана - добавить  
    - если имя задано - добавить (с пробелом, если строка не пустая)  
    - если отчество задано - добавить (с пробелом)  
    - вернуть собранную строку  
Незаданные части не включаются.
5. Создать объекты имён.  
    - new Name("Клеопатра")  
    - new Name("Пушкин", "Александр", "Сергеевич")
    - new Name("Маяковский", "Владимир")
6. Вывести имена на экран.
